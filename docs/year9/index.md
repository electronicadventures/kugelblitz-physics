## Test revision: atoms, radioactivity and chemical change

Work through these in order. Each page has worked examples, an interactive tool and a self-check.

| Page | What it's about |
|---|---|
| [The periodic table, electron shells and reactivity](lessons/periodic-table-shells-reactivity.md) | Find elements by group and period, draw electron shells, and predict and justify reactivity. |

| [Isotopes](lessons/isotopes.md) | Same element, different neutrons: read an isotope table and compare two isotopes. |
| [Half-life graphs and alpha decay](lessons/half-life-and-alpha-decay.md) | Read a half-life from a graph, describe the trend, and work through alpha decay. |
