## Two numbers tell you everything

<ul><li><strong>Atomic number</strong> = number of <strong>protons</strong>. It decides which element the atom is. In a neutral atom it also equals the number of <strong>electrons</strong>.</li>
<li><strong>Mass number</strong> = protons + neutrons (the particles in the nucleus). Electrons are too light to count.</li></ul>
<div class="admonition tip"><p style="margin:0;"><strong>So:</strong> protons = atomic number · electrons = atomic number · <strong>neutrons = mass number − atomic number</strong></p></div>
<p><strong>Nuclear notation</strong> puts the mass number on top and the atomic number underneath, to the left of the symbol: <span class="nuc"><span class="nuc-n"><span>24</span><span>12</span></span>Mg</span> is magnesium with mass number 24 and atomic number 12.</p>
<p>On a periodic table the mass is often given with decimals (magnesium 24.31). Round it to the nearest whole number (24) to get the mass number of the most common atom.</p>

<details class="example" id="worked-example-completing-a-particle-table"><summary>Worked example: completing a particle table</summary>
<p>Use the periodic table to complete the table.</p><hr>
<table><thead><tr><th>Symbol</th><th>Atomic number</th><th>Mass number</th><th>Protons</th><th>Neutrons</th><th>Electrons</th></tr></thead><tbody>
<tr><td><strong>Mg</strong></td><td>12</td><td><strong>24</strong></td><td><strong>12</strong></td><td><strong>24 − 12 = 12</strong></td><td><strong>12</strong></td></tr>
<tr><td><strong>P</strong></td><td><strong>15</strong></td><td>31</td><td><strong>15</strong></td><td><strong>31 − 15 = 16</strong></td><td><strong>15</strong></td></tr>
<tr><td><strong>K</strong></td><td><strong>19</strong></td><td><strong>39</strong></td><td><strong>19</strong></td><td><strong>39 − 19 = 20</strong></td><td>19</td></tr>
</tbody></table>
<p>How each row was found:</p>
<ul><li><strong>Mg:</strong> atomic number 12 → find magnesium on the table; its mass number is 24.</li>
<li><strong>P:</strong> mass number 31 → phosphorus, atomic number 15.</li>
<li><strong>K:</strong> 19 electrons → a neutral atom, so 19 protons → atomic number 19 → potassium, mass number 39.</li></ul>
<p>Whatever you are given, first find the <strong>element</strong>. Then everything else follows.</p>
</details>

<details class="note" id="common-mistakes"><summary>Common mistakes</summary>
<ul><li><strong>Neutrons = atomic number.</strong> Only sometimes true by coincidence (as for magnesium-24). Always subtract: mass number − atomic number.</li>
<li><strong>Electrons = mass number.</strong> Electrons equal the <em>protons</em>, not protons + neutrons.</li>
<li><strong>Swapping the numbers.</strong> The mass number is always the <em>bigger</em> one (except hydrogen-1, where they are equal).</li></ul>
</details>

<p><strong>1.</strong> An atom of aluminium has atomic number 13 and mass number 27. How many neutrons does it have?</p>
<div class="sc-num" data-answer="14" data-tol="0.001" data-unit="neutrons" data-alt="13:That is the number of protons. Neutrons = mass number − atomic number.|27:That is the mass number (protons + neutrons together). Subtract the protons.|40:You added. Neutrons = 27 − 13."></div>
<details class="success"><summary>Worked solution</summary><p>27 − 13 = <strong>14 neutrons</strong>.</p></details>

---

<p><strong>2.</strong> An atom has 8 protons and 10 neutrons. What is its mass number?</p>
<div class="sc-num" data-answer="18" data-tol="0.001" data-alt="8:That is the atomic number. The mass number counts protons AND neutrons.|2:Add, don't subtract: mass number = protons + neutrons."></div>
<details class="success"><summary>Worked solution</summary><p>8 + 10 = <strong>18</strong>. It is oxygen-18 (8 protons means oxygen).</p></details>
