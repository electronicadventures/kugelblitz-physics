# Range and launch angle: interpreting data

<span class="checklist-codes">G1.5</span> <span class="checklist-codes">G1.4</span>

!!! abstract "By the end of this lesson you should be able to"
    - Interpret data relating to the horizontal distance travelled by an object projected at various angles from the horizontal. <span class="checklist-codes">G1.5</span>
    - Solve problems involving projectile motion in the absence of drag effects using v_y = u_y + gt, s_y = u_y t + ½gt^2, v_y^2 = u_y^2 + 2gs_y, v_x = u_x and s_x = u_x t. <span class="checklist-codes">G1.4</span>

## Key ideas

- For the same launch speed on level ground, range depends on \(\sin 2\theta\): maximum at 45°.
- Complementary angles (e.g. 30° and 60°) give the **same range** but different heights and flight times.
- To test the model, **linearise**: plot range against \(\sin 2\theta\). A straight line through the origin supports the model; the gradient is \(u^2/g\).
- Real data falls short at large angles and over long flights because of air resistance and launch-height differences.

!!! note "Key formulas (QCAA formula book notation)"

    \[
    \text{range} = \frac{u^2 \sin 2\theta}{g} \quad \text{(level ground, no air resistance)}
    \]


??? example "Worked example"
    **A launcher gives a range of 4.0 m at 45°. Predict the range at 15° (same speed, level ground).**

    1. Range \(\propto \sin 2\theta\): \(4.0 \times \sin 30^\circ / \sin 90^\circ = 2.0\) m

!!! warning "Common mistakes"
    - Expecting double the angle to give double the range.
    - Plotting range against θ and calling the curve 'linear'.
    - Forgetting that the range formula only works for level ground.
