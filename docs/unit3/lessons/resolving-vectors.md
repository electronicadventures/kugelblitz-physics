# Resolving vectors into components

<span class="checklist-codes">G1.1</span>

!!! abstract "By the end of this lesson you should be able to"
    - Apply vector analysis to resolve a vector into two perpendicular components. <span class="checklist-codes">G1.1</span>

## Key ideas

- A **vector** has magnitude and direction; a **scalar** has magnitude only.
- Any 2D vector can be split (**resolved**) into two perpendicular **components**, usually horizontal (x) and vertical (y).
- The components are the sides of a right-angled triangle; the original vector is the hypotenuse.
- Measure θ from the positive x-axis (anticlockwise) and the signs of the components look after themselves. Otherwise use the acute angle and assign signs from the diagram.

!!! note "Key formulas (QCAA formula book notation)"

    \[
    v_x = v\cos\theta
    \]

    \[
    v_y = v\sin\theta
    \]


??? example "Worked example"
    **A force of 50 N acts at 30° above the horizontal. Find its horizontal and vertical components.**

    1. \(F_x = 50\cos 30^\circ = 43.3\) N
    2. \(F_y = 50\sin 30^\circ = 25.0\) N
    3. Check: \(\sqrt{43.3^2 + 25.0^2} = 50\) N ✓

!!! warning "Common mistakes"
    - Swapping sin and cos. *cos* goes with the side **adjacent** to the angle.
    - Calculator in radians instead of degrees.
    - Forgetting negative signs for components pointing left or down.
