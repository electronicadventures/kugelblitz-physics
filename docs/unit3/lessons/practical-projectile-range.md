# Practical: projectile range at various angles

<span class="checklist-codes">G5.2</span> <span class="checklist-codes">G1.5</span>

!!! abstract "By the end of this lesson you should be able to"
    - Investigate the horizontal distance travelled by an object projected at various angles from the horizontal. <span class="checklist-codes">G5.2</span>
    - Interpret data relating to the horizontal distance travelled by an object projected at various angles from the horizontal. <span class="checklist-codes">G1.5</span>

## Key ideas

- **Aim:** investigate how horizontal distance depends on launch angle (G5.2).
- **Independent variable:** launch angle. **Dependent:** horizontal range. **Controlled:** launch speed, launch height, projectile.
- Take at least 3 trials per angle; report the mean ± (max − min)/2.
- **Analysis:** plot range vs sin 2θ with error bars, draw best-fit and worst-fit lines, and use the gradient (u²/g) to find the launch speed.
- **Evaluate:** air resistance, launch height above the landing point, consistency of launch speed.

!!! note "Key formulas (QCAA formula book notation)"

    \[
    \text{range} = \frac{u^2}{g}\sin 2\theta \Rightarrow \text{gradient} = \frac{u^2}{g}
    \]


!!! warning "Common mistakes"
    - Too few angles near 45° to see the peak.
    - Not measuring range from directly below the launch point.
