# Practical: weight component down an incline

<span class="checklist-codes">G5.3</span>

!!! abstract "By the end of this lesson you should be able to"
    - Investigate the parallel component of the weight of an object down an inclined plane at various angles. <span class="checklist-codes">G5.3</span>

## Key ideas

- **Aim:** investigate how the parallel component of weight changes with incline angle (G5.3).
- **IV:** angle (set by height h and ramp length l, \(\sin\theta = h/l\)). **DV:** force to hold the object still (spring balance or force sensor). **Controlled:** mass, surface.
- **Analysis:** plot F against sin θ. The model predicts a straight line through the origin with gradient mg.
- **Evaluate:** friction, reading the spring balance, measuring small angles.

!!! note "Key formulas (QCAA formula book notation)"

    \[
    F_\parallel = m g \sin\theta \Rightarrow \text{gradient} = m g
    \]


!!! warning "Common mistakes"
    - Pulling the spring balance at an angle to the slope.
    - Not zeroing the force meter.
