# Inclined planes with applied force and connected masses

<span class="checklist-codes">G2.3</span> <span class="checklist-codes">G2.4</span>

!!! abstract "By the end of this lesson you should be able to"
    - Describe the forces acting on an object on an inclined plane through the use of free-body diagrams. <span class="checklist-codes">G2.3</span>
    - Determine the net force acting on an object on an inclined plane using vector analysis. <span class="checklist-codes">G2.4</span>

## Key ideas

- Choose a positive direction along the slope (usually the direction of motion) and add forces with signs.
- An **applied force along the slope** needs no resolving.
- Friction always opposes the motion (or the tendency to move).
- For connected masses on a light string over a frictionless pulley, the tension is the same at both ends and both masses share the same acceleration.

!!! note "Key formulas (QCAA formula book notation)"

    \[
    F_{net} = F_A - m g\sin\theta - F_f = m a \quad \text{(pushed up the slope)}
    \]


??? example "Worked example"
    **A 900 kg car accelerates up a 10° hill at 0.50 m s⁻² against 600 N of friction. Find the driving force.**

    1. \(m g\sin\theta = 900 \times 9.8 \times \sin 10^\circ = 1532\) N
    2. \(F_A = ma + mg\sin\theta + F_f = 450 + 1532 + 600 = 2.6 \times 10^3\) N

!!! warning "Common mistakes"
    - Forgetting the weight component when moving up a slope.
    - Giving each connected mass a different acceleration.
